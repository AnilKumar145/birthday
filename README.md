# MAYBE IT WAS DESTINY ❤️
### A Birthday Story Dedicated to Bujjamma
**Created with love by Anil (Nani)**

> *"Out of all the people, places, and unexpected moments in this world, somehow our paths crossed."*

A premium, emotionally engaging, interactive birthday storytelling web application built with React, Vite, Framer Motion, and CSS3 animations.

---

## 🌟 The Complete Story Journey

1. **Midnight Countdown Screen** — Accurate Indian Standard Time (Asia/Kolkata) countdown to November 22, 2026 midnight, with immediate "Enter Early" access and preview options.
2. **Chapter 00 — The Invitation** — Cinematic starry night sky with golden particles, floating rose petals, and progressive text reveal.
3. **Chapter 01 — An Unexpected Beginning** — How Anil and Bujjamma met at SVC College, Tirupati during student hackathon presentations (representing TalentShala Global).
4. **Chapter 02 — Small Moments, Special Feelings** — Her affectionate coffee invitations ("*Coffee thagudama, sir?*") with an interactive steaming coffee mug.
5. **Chapter 03 — When Distance Entered the Story** — The departure to Bengaluru, her emotional questions (*"When will you come back?"*), and glowing connection across miles.
6. **Chapter 04 — A Message, A Moment, A Little Destiny** — The famous single-tick to double-tick heart-stopping moment, with custom stylized interactive mobile chat replay.
7. **Chapter 05 — A Memory Called October 12** — One precious hour together at Cream Stone with interactive dessert and revolving clock.
8. **Chapter 06 — And Here We Are... (Our Little World)** — A mature, honest, and hopeful reflection on the bond, with dynamic countdown to the upcoming November 29 meeting.
9. **Chapter 07 — A Letter From Your Nani** — Animated wax seal envelope unfolding into a handwritten cream parchment love letter.
10. **Chapter 08 — 10 Little Things That Make You Special** — 10 interactive 3D flip cards with custom romantic micro-interactions.
11. **Chapter 09 — Make Your Birthday Wish (The Grand Finale)** — 3-tier birthday cake with flickering candles, blowout animation, celebratory golden fireworks, confetti shower, and final message.

## 🎵 Audio Experience

- Built-in romantic Web Audio API synthesizer (warm harmonic pad in D major + celestial music-box lullaby) — **100% zero external dependencies, copyright-free, and instant loading**.
- Optional custom MP3 audio support: place any audio file at `public/music/romantic.mp3`.
- Interactive sound effects for coffee sipping, card flips, heart chimes, and candle blowout.

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

---

## ☁️ Deployment to Vercel

```bash
# Using Vercel CLI
npx vercel
```
Or push to GitHub and connect repository to [Vercel](https://vercel.com).
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
